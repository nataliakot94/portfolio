## 📁 Проекты и кейсы

### 1. Аналитика маркетинговых кампаний в ритейле
* **Что сделано:** Реализован на Python (`Pandas`, `SciPy`) полный цикл оценки A/B-теста — от Data Cleaning до проверки стат-гипотез ($t$-test, критерий Манна-Уитни) в разрезе городов присутствия.
* **Результат:** Создан интерактивный калькулятор в Excel с автоматическим расчетом бизнес-метрик для кросс-функциональных команд.

### 2. Аналитика торгового ретейлера
* **Что сделано:** Консолидировала данные по инцидентам, рассчитала их финансовое влияние. Провела аудит маркетинговой эффективности акций и подготовила план их оптимизации.
* **Результат:** Внедрение интерактивных дашбордов в Google Sheets с пользовательскими инструкциями.

### 3. Анализ онлайн-кинотеатра
* **Что сделано:** Оцифровала метрики удержания аудитории (**Retention**) и пожизненной ценности клиента (**LTV**).
* **Результат:** Выявила ключевые причины оттока зрителей сериалов и сформировала гипотезы по их устранению.

### 4. Анализ метрик компьютерной игры
* **Что сделано:** Рассчитала продуктовые (DAU, MAU, сессии) и монетизационные (ARPU, ARPPU) показатели, построила конверсионные воронки.
* **Результат:** Оценила эффективность рекламных кампаний и их непосредственное влияние на бизнес-показатели.
